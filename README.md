# Site JWR — Jhonata, Wallysson e Robert

Projeto de site/portfólio responsivo feito com HTML, CSS e JavaScript puro.

## Como abrir no VSCode
1. Extraia o arquivo ZIP.
2. Abra a pasta `site_jhonata_wallysson_robert` no Visual Studio Code.
3. Abra `index.html` no navegador ou use a extensão **Live Server**.
4. Edite `index.html`, `css/style.css` e `js/script.js` para personalizar.

O formulário é demonstrativo: não envia mensagens para um servidor.
